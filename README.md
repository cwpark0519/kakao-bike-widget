# 카카오바이크 위젯 미리보기

## 파일 구성
- `index.html`: 웹페이지 구조
- `style.css`: 화면 배치와 배경 스타일
- `images/widget.png`: 위젯 이미지

## GitHub에 올리는 방법
1. GitHub 저장소 `kakao-bike-widget`에 들어갑니다.
2. `Add file` → `Upload files`를 누릅니다.
3. 압축을 푼 폴더 안의 `index.html`, `style.css`, `images` 폴더를 업로드합니다.
4. `Commit changes`를 누릅니다.
5. 저장소 `Settings` → `Pages`에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.

참고: 이 프로젝트는 위젯 이미지를 웹페이지에 표시하는 미리보기입니다.
실제 아이폰 홈 화면 위젯으로 설치되는 iOS 앱은 아닙니다.
